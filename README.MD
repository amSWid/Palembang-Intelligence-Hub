# 🏙️ Palembang Intelligence Hub

An AI-powered Tourism & Investment Assistant built with Streamlit, Retrieval-Augmented Generation (RAG), ChromaDB, and Groq.

## Project Overview

Palembang Intelligence Hub is an intelligent assistant that helps users explore the city of Palembang through natural language.

The assistant can answer questions about:

- 🏛 History
- 🎭 Culture
- 🍜 Traditional Food
- 📈 Economy
- 💼 Investment Opportunities

The application combines local knowledge sources with Retrieval-Augmented Generation (RAG) to produce contextual answers.

---

## Features

- AI Tourism Assistant
- AI Investment Assistant
- Local Knowledge Search
- Multi-document Retrieval
- Source References
- Interactive Streamlit Interface

---

## Technology Stack

- Python
- Streamlit
- ChromaDB
- Sentence Transformers
- Groq LLM
- RAG (Retrieval-Augmented Generation)
